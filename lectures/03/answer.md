## 宿題

- 取り組んだレベル：実装
- やったこと：
  - `app/tools.py` に `save_learning_log(title, content)` を追加した。`learning_log/日時_見出し.md` に Markdown で保存する。同じ見出しでも上書きしないようにし、ファイル名に使えない文字は `_` に置き換える。title か content が空なら保存しない
  - `app/agent.py` で `requires_approval=True` を付けて登録し、`output_type=[str, DeferredToolRequests]` にした
  - CLI に `run_with_approval` と `ask_approvals` を追加した。結果が `DeferredToolRequests` なら、`approvals` の呼び出しごとに保存する見出しと本文を表示し、`[y/N]` で聞く。`y` なら `True`、それ以外なら `ToolDenied("…保存していません。")` を `DeferredToolResults` に入れ、`message_history=result.all_messages()` と一緒に、もう一度 `run_sync` を実行する。対話できないとき（`EOFError`）は拒否として扱う
  - `tests/test_learning_log.py` を追加した（API キー不要、保存先は一時フォルダ）。承認待ちで止まって書き込まないこと、承認すると保存されること、拒否すると保存されないこと、usage が足し上げられることを確かめる
- 結果：
  - 承認（`y`）：`search_glossary` → `save_learning_log`（承認待ち）→ 承認 → `learning_log/20261109-154206_PEFTについて.md` が作られ、「記録として保存しました」と回答した
  - 拒否（`n`）：同じ流れで承認待ちになり、拒否すると何も保存されず、「承認が得られなかったため、保存していません」と回答した
  - 保存を頼まない質問（「PEFTとは？」）では、`save_learning_log` は呼ばれなかった
  - 途中で見つかった問題と直したこと：

    | 問題 | 原因 | 直したこと |
    |---|---|---|
    | 保存を頼んでも `save_learning_log` を呼ばず、「保存しますか？」と文章で聞き返して終わった | `INSTRUCTIONS` の「保存するかどうかは利用者が承認する」と docstring の「保存の前に利用者の承認を求める」を、モデルが「呼ぶ前に自分で確認する」と解釈した | 「文章で確認せずに呼ぶ（承認はシステムが利用者に求める）」と書き換えた |
    | 拒否したのに「保存用の操作を行いました（承認が必要な場合があります）」と、保存したかのように読める回答をした | ツールは「保存していません」と返していたが、伝え方の指示が無かった | `INSTRUCTIONS` に「承認されず保存しなかったときは、『保存していない』とはっきり伝える」を足した |
    | `[usage]` の `requests` が 1 になった（実際は 3 回） | 承認後の `run_sync` は別の実行なので、最後の実行の分しか数えていなかった | 承認後の実行に `usage=result.usage` を渡して足し上げた |
    | 保存したファイルの見出しが二重になった | モデルが content の先頭にも `# 見出し` を書いた | docstring に「見出しは自動で付くので content には書かない」と書き、title と同じ見出しはコードでも外すようにした |
- 気づき・疑問：
  - 承認は、モデルではなくプログラム（CLI）が行う仕組みなので、モデルへの指示には「呼んでよい、承認はシステムがする」と書く必要があった。「承認が必要」とだけ書くと、モデルが自分で確認しようとして、ツールが呼ばれなくなる。指示に書く内容は、モデルの役割とシステムの役割を分けて書くとよいと分かった
  - 承認を挟むと LLM の呼び出しが増える（1つの質問で 2 回 → 3 回）。無料枠のレート制限があるので、承認が必要なのは本当に取り消しにくい操作だけに絞るのがよいと考える
  - 拒否した結果がモデルに戻るので、モデルは「保存していない」ことを知ったうえで回答できる。ただし伝え方は指示しないと曖昧になった。取り消しにくい操作では、実際に何が起きたかを利用者に正しく伝えることも、承認の仕組みの一部だと感じた
  - 疑問：承認の画面で、利用者が本文を直してから保存したい場合はどうするのがよいか（`DeferredToolResults` でツールの引数を差し替えられるか）
